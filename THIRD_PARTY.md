# Dependencias incluidas

La aplicación no descarga dependencias al abrirse ni necesita instalación de paquetes.

- **QR Code Generator for JavaScript**, Kazuhiko Arase. Licencia MIT. Código de https://github.com/kazuhikoarase/qrcode-generator, archivo `js/dist/qrcode.js`. Aviso de licencia conservado en `vendor/qrcode.js`.
- **jsQR**, Cozmo, LLC. Licencia Apache-2.0. Código de https://github.com/cozmo/jsQR, archivo `dist/jsQR.js`. El lector se carga únicamente al activar la cámara. Licencia en `vendor/jsqr-LICENSE.txt`.
